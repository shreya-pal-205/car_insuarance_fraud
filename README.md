**Car Insurance Fraud Detection System** 🚗🔍
This project is a Machine Learning–powered Fraud Detection System designed to identify potential car insurance fraud based on user-submitted claim details. It helps insurers analyze claim patterns and flag suspicious activity, reducing financial losses and improving decision-making.

🔧**Tech Stack Used**

1. Python
2. Flask (Backend API + routing)
3. HTML, CSS (Frontend UI)
4. Machine Learning Model (Scikit-Learn)
5. NumPy, Pandas (Data processing)
6. Gunicorn (Production server for deployment)
7. Render (Hosting platform)

✨**Key Features**

1. Predicts whether a car insurance claim is fraudulent or genuine
2. Simple and user-friendly web interface
3. Real-time prediction using a trained ML model
4. Modular and scalable Flask architecture
